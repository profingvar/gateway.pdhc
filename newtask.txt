What #871 turned out to be
--------------------------
NOT plan-vs-gateway, which is how the ticket read. The disagreement was
between gateway's own producer and its own consumers, with no network between
them:

    producer  _extract_qr_answer        numeric text boolean date datetime choice
    consumer  _SURVEY_TYPES             categorical boolean text dateTime graph
    consumer  VALID_RESPONSE_TYPES      numeric categorical text boolean dateTime graph

`text` and `boolean` matched; `choice`/`datetime`/`date` did not. #489 fixed
quantity-coercion of a coded value for the spelling `categorical`, and the
producer spelled it `choice` — so the fix for "the core corruption bug" existed,
was tested, and the producer routed around it. A Likert "5" became a
valueQuantity.

Live on the QuestionnaireResponse path ONLY: `_store_questionnaire_response`
never calls the validator. The provider-report path (`ingest`) validated
against the canonical six all along.
